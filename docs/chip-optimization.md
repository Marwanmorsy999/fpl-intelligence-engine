# Chip Optimization

The `ChipSimulator` estimates the immediate and multi-gameweek value of playing chips.

## Handled Chips
- **Bench Boost**: Focuses on bench minutes probability and double gameweeks.
- **Triple Captain**: Multiplies EV but accounts for variance and minutes probability across multiple fixtures.
- **Wildcard/Free Hit**: To be fully supported through multi-GW squad rebuilding using the optimizer.
