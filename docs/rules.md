# FPL Rules Versioning

The application treats FPL rules as season-specific configuration and code.

For 2026/27, the official Premier League announced changes including:

- a Price Change Predictor based on official FPL transfer activity
- later Gameweek lockdown at 09:00 UK time the day after the final Gameweek match
- two sets of Wildcard, Free Hit, Triple Captain and Bench Boost chips
- up to five rolled free transfers
- revised Bonus Points System mechanics
- continued Defensive Contribution Points with 2026/27-specific details

The scoring engine must validate all scoring constants against the official rules before production use.
